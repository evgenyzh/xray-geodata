# xray-geodata

Compiled geodata for Xray. The `release` branch and GitHub Releases provide
`geosite.dat`, `geoip.dat`, `manifest.json` and checksum files.

Verify artifacts with `sha256sum -c SHA256SUMS`. Individual `.sha256` files
contain only a lowercase SHA-256 hex digest and a newline. License notices are
distributed alongside the artifacts.
